定义 10.1.1 / 10.1.2

半群：封闭加结合

\[\displaystyle (a \odot b) \odot c = a \odot (b \odot c)\]

若运算 ☉ 在集合上封闭且满足结合律，则 \(\langle S,\odot \rangle\) 是半群。若 T 是半群 S 的非空子集且在同一运算下也构成半群，则 \(\langle T,\odot \rangle\) 是 \(\langle S,\odot \rangle\) 的子半群。

元素的阶：使 \(g^{n}\) 回到单位元的最小 n

\[\displaystyle \operatorname{ord}(g) = \operatorname{min}\{ n > 0 : g^{n}= e \}\]

阶与整除

\(g^{k}\) 回到单位元当且仅当阶整除 k

\[\displaystyle g^{k}= e \Longleftrightarrow \operatorname{ord}(g) | k\]

子群：本身成群的子集

置换分解

正规子群：对共轭封闭

循环群 · 密钥生成

基于循环群的密钥生成

选素数 p，在模 p 非零剩余类乘法群 \(F_{p}*\)（阶为 p−1）中找生成元（原根）g，用随机指数 k 计算 \(g^{k} \operatorname{mod} p\) 得到密钥。循环群的性质保证密钥复杂、随机且不易预测，记录已生成密钥以避免重复。

Python 实现
import secrets
class CyclicGroup:
    def __init__(self, p):
        self.p = p
        self.g = self.find_generator()
        self.used = set()
    def is_generator(self, g):
        return len({pow(g, i, self.p)
                    for i in range(self.p - 1)}) == self.p - 1
    def find_generator(self):
        for g in range(2, self.p):
            if self.is_generator(g):
                return g
    def generate_key(self):
        while True:
            k = secrets.randbelow(self.p - 1) + 1
            key = pow(self.g, k, self.p)
            if key not in self.used:
                self.used.add(key); return key

有限域乘法群 · Reed-Solomon

北斗导航的纠错编码

在有限域 \(GF(2^{8})\) 上，所有非零元素构成乘法循环群。利用该群性质做多项式运算，构建 Reed-Solomon 码：信息多项式除以生成多项式得带校验的码字，接收端检错纠错，提升北斗卫星通信可靠性。

\(GF(2^{8})\) 核心结构 · 非完整编码器
PRIM = 0x11D
def gf_mul(a, b):
    p = 0
    for _ in range(8):
        if b & 1: p ^= a
        hi = a & 0x80
        a = (a << 1) & 0xFF
        if hi: a ^= PRIM & 0xFF
        b >>= 1
    return p
def gf_pow(a, n):
    r = 1
    for _ in range(n): r = gf_mul(r, a)
    return r
def poly_mul(p, q):
    out = [0] * (len(p) + len(q) - 1)
    for i, x in enumerate(p):
        for j, y in enumerate(q): out[i+j] ^= gf_mul(x, y)
    return out
def generator_poly(nsym):
    g = [1]
    for i in range(nsym): g = poly_mul(g, [1, gf_pow(2, i)])
    return g

陪集 · 对称群加密

基于陪集的对称群加密

取对称群 \(S_{3}\) 为 G、二阶子群为 H。由拉格朗日定理 G 被划分为 3 个陪集。加密把消息映射到陪集，解密通过识别消息所属陪集还原原文，体现陪集划分在密码设计中的结构价值。

Python 实现
from sympy.combinatorics import Permutation, PermutationGroup
G = PermutationGroup([Permutation([1,0,2]), Permutation([2,1,0])])
H = PermutationGroup([Permutation([1,0,2])])
def left_cosets(G, H):
    cosets = []
    for g in G.generate():
        c = [g*h for h in H.generate()]
        if not any(set(c)==set(e) for e in cosets):
            cosets.append(c)
    return cosets
cosets = left_cosets(G, H)
def encrypt(m): return cosets[m % len(cosets)][0]
def decrypt(c):
    return next(i for i,ct in enumerate(cosets) if c in ct)
