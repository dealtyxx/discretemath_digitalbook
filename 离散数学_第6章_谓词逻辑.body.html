定义 6.1.1 至 6.1.3

个体常元、个体变元与个体域

个体词引用世界中的具体对象。个体常元值不变，用 a, b, c 表示特定对象，如 a 代表王五；个体变元可变，用 x, y, z 表示。

个体域是个体变元的取值范围；全总个体域是所讨论的所有个体的集合，个体域通常是它的子集。如讨论实数时全总个体域是所有实数，讨论某校学生时是该校全体学生。

定义 6.1.6 至 6.1.8 · 全称与存在量词

全称量词 ∀ 与存在量词 ∃

\[\displaystyle \forall xP(x) = P(a_{1})\land \ldots \land P(a_{n}) \exists xP(x) = P(a_{1})\lor \ldots \lor P(a_{n})\]

\(\forall xP(x)\) 为真当且仅当个体域中每个 x 都使 \(P(x)\) 真；\(\exists xP(x)\) 为真当且仅当至少存在一个 x 使 \(P(x)\) 真。量词限定变量是对所有个体还是某些个体。

6.2.1 谓词公式与解释
21 / 76
定义 6.2.1 · 谓词公式

原子公式加递归规则

若 P 是 n 元谓词、\(t_{1},\ldots ,t_{n}\) 是项（个体常量、变量或函数表达式），则 \(P(t_{1},\ldots ,t_{n})\) 是原子公式。

递归规则：原子公式是谓词公式；若 φ 是公式则 \(\neg φ\) 是公式；\(φ\land ψ\)、\(φ\lor ψ\)、\(φ\to ψ\)、\(φ\leftrightarrow ψ\) 都是公式；若 φ 是公式且 x 是变量则 \(\forall x(φ)\)、\(\exists x(φ)\) 也是公式；有限次应用上述规则所得即谓词公式。

6.2.1 辖域与约束变元
22 / 76
定义 6.2.2 · 辖域、约束与自由变元

量词的辖域决定约束的有效范围

\(\forall xB(x)\) 或 \(\exists xB(x)\) 中 B(x) 是量词的辖域。辖域中的 x 是约束出现（约束变元），B 中其他变元的出现是自由出现（自由变元）。

例 6.2.1 与 6.2.2

例 6.2.1：\(\forall x((S(x)\land M(x))\to \exists y(P(y)\land K(x,y)))\) 中 \(\forall x\) 辖域是整个蕴含式，\(\exists y\) 辖域是 \(P(y)\land K(x,y)\)，x、y 都是约束变元。例 6.2.2：所有的猫都怕水 \(\forall x(C(x)\to F(x))\)（全称量词配蕴含，用合取会错误地断言"万物皆猫且怕水"）。

闭式、约束变元换名与自由变元代入

无自由出现个体变元的公式称为闭式。例 6.2.3：\(\forall x(P(x)\to Q(x))\) 是闭式，\(\forall x(P(x)\to Q(x,y))\) 因 y 自由而不是闭式。

约束变元换名：把约束变元改成辖域中未出现的新变元，如 \(\forall x\exists y(S(x)\to L(x,y))\) 换为 \(\forall z\exists w(S(z)\to L(z,w))\)。自由变元代入：把自由变元 x 替换为项 t，记 F[t/x]。

例 6.2.9 · 在解释 I 下求真值

解释 I 下三个公式的真值

\(D_{I}=\{3,6\}\)，\(a=3\)，\(f(3)=6,f(6)=3\)，\(P(3)=0,P(6)=1\)，Q 对任意 i,j 取 1，\(R(3,3)=R(6,6)=1\)。则 \(\forall x(P(x)\land Q(x,a))=0\)；\(\exists x(P(f(x))\land Q(x,f(x)))=1\)；\(\forall x\exists yR(x,y)=1\)。

Python 实现
D = [3, 6]                          # 个体域 D_I
a = 3                               # 特定元素
def f(x): return 6 if x == 3 else 3 # f(3)=6, f(6)=3
def P(x): return x == 6             # P(3)=0, P(6)=1
def Q(x, y): return True            # Q(i,j)=1, 对所有 i,j∈D
def R(x, y): return x == y          # R(3,3)=R(6,6)=1, 其余 0

print(all(P(x) and Q(x, a) for x in D))            # ∀x(P(x)∧Q(x,a)) -> False
print(any(P(f(x)) and Q(x, f(x)) for x in D))      # ∃x(...) -> True
print(all(any(R(x, y) for y in D) for x in D))     # ∀x∃yR(x,y) -> True

定义 6.2.7 · 三种公式

逻辑有效式、矛盾式与可满足式

在任何解释下都为真的公式是逻辑有效式（永真式）；都为假的是矛盾式（永假式）；至少有一个解释为真的是可满足式。

例 6.2.10：\(\forall xP(x)\to \exists xP(x)\) 是永真式；\(\forall x\exists yP(x,y)\to \exists x\forall yP(x,y)\) 在 P 为 \(x=y\) 时后件假而前件真，是可满足式而非永真。

谓词逻辑等价与命题等价式的推广

若 \(A\leftrightarrow B\) 逻辑有效，则 A 与 B 是等价式，记 \(A\Leftrightarrow B\)。命题逻辑的基本等价式都可推广到谓词逻辑。

6.2.2 谓词逻辑蕴含
32 / 76
定义 6.2.9 与 例 6.2.12 至 6.2.14

谓词逻辑的基本蕴含式

\(A\Rightarrow B\) 当且仅当 \(A\to B\) 逻辑有效。单变元蕴含式如 \(\forall xA(x)\lor \forall xB(x) \Rightarrow \forall x(A(x)\lor B(x))\)；\(\exists x(A(x)\land B(x)) \Rightarrow \exists xA(x)\land \exists xB(x)\)；\(\forall x(A(x)\to B(x)) \Rightarrow \forall xA(x)\to \forall xB(x)\)。

二元蕴含式如 \(\forall x\forall yA(x,y) \Rightarrow \forall xA(x,x)\)；\(\exists xA(x,x) \Rightarrow \exists x\exists yA(x,y)\)；\(\forall x\exists yA(x,y) \Rightarrow \exists y\exists xA(x,y)\)。例 6.2.14 证 \(\forall x\forall y(P(x)\leftrightarrow Q(y)) \Rightarrow \forall xP(x)\leftrightarrow \forall xQ(x)\)。

所有量词都提到公式最前面

谓词规则匹配学生与国家需求

定义谓词 MajorIn、InterestIn、AbleIn、NationNeed、Match、Recommend，构建规则 \(\forall x,y,z,w,p(MajorIn(x,y)\land InterestIn(x,z)\land AbleIn(x,w)\land NationNeed(y)\land Match(y,z,w,p)\to Recommend(x,p))\)，把学生专业兴趣能力与国家需求匹配到职业路径。

Python 实现
students = [
    {"name": "李明", "major": "计算机科学",
     "interests": ["人工智能", "数据科学"], "abilities": ["编码", "数学"]},
    {"name": "张梅梅", "major": "电气工程",
     "interests": ["机器人", "可再生能源"], "abilities": ["集成电路设计", "数学"]},
]
nation_needs = ["计算机科学", "电气工程", "可再生能源"]
career_paths = {
    ("计算机科学", "人工智能", "编码"): "人工智能研究员",
    ("电气工程", "机器人", "集成电路设计"): "机器人研发工程师",
}

def match(major, interests, abilities):     # 专业∧兴趣∧能力∧国家需求→职业
    if major not in nation_needs:
        return None
    for i in interests:
        for a in abilities:
            if (major, i, a) in career_paths:
                return career_paths[(major, i, a)]
    return None

for s in students:
    path = match(s["major"], s["interests"], s["abilities"])
    if path:
        print(f"{s['name']}，建议从事的职业: {path}")

定义谓词 Unique、InDanger、UNESCOHeritage、PriorityForProtection，构建规则 \(\forall x(Unique(x)\land InDanger(x)\to \text{优先保护})、\forall x(UNESCOHeritage(x)\to \text{优先保护})\)。独一无二且危险，或被列为世界遗产的遗迹应优先保护。

Python 实现
heritages = {
    '长城':   {'unique': True,  'in_danger': True,  'unesco_heritage': True},
    '兵马俑': {'unique': True,  'in_danger': False, 'unesco_heritage': True},
    '紫禁城': {'unique': False, 'in_danger': False, 'unesco_heritage': True},
}

def should_protect(p):                      # 独特且危险 或 世界遗产
    if p['unique'] and p['in_danger']:
        return True
    return p['unesco_heritage']

for name, p in heritages.items():
    if should_protect(p):
        print(f"{name}应该优先保护")

案例二 · 综合评估

扩展为多维度保护决策

进一步考虑历史价值、文化影响力、经济条件、保护成本与潜在效益等多维因素，构建综合规则：独特且危险，或高价值且高影响力，或经济好且成本低且效益高，则推荐优先保护。

Python 实现
def recommend(p):
    unique_danger = p['unique'] and p['in_danger']
    value_influence = (p['historical_value'] == 'high'
                       and p['cultural_influence'] == 'high')
    cost_benefit = (p['economic_condition'] == 'good'
                    and p['protection_cost'] == 'low'
                    and p['potential_benefit'] == 'high')
    return unique_danger or value_influence or cost_benefit

for name, p in heritages.items():
    if recommend(p):
        print(f"{name} 建议优先保护")
