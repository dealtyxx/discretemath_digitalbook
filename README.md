# 离散数学 · 交互式数字教材（发布版）

## 打开方式

双击 `index.html`（全书目录）即可在浏览器中使用，无需联网、无需安装任何软件。
推荐使用 Chrome / Edge 最新版本。

## 内容构成

| 文件 | 说明 |
|------|------|
| `index.html` | 全书目录（11 章入口 + 作者声明音频 + 资源总览） |
| `离散数学_第N章_*.html` | 各章入口页（自适应缩放舞台） |
| `离散数学_第N章_*.body.html` | 各章正文内容（由入口页自动加载，勿单独打开） |
| `assets/micro-lectures/` | 36 讲微课视频，约 293 分钟 |
| `assets/podcasts/` | 36 期播客音频 + 作者声明，约 318 分钟 |
| `assets/source-code/` | 253 段 Python 配套源码，按 `CH1`…`CH11` 分目录，共 3792 行 |
| `assets/app-videos-ch1` … `-ch11` | 应用案例教学动画 |
| `assets/mathjax`、`assets/@mathjax` | 公式渲染引擎（本地化，离线可用） |
| `assets/fonts/` | 页面字体（本地化，离线可用，许可证见 `assets/fonts/LICENSES/`） |

共 11 章、996 页知识页，含定义、定理、例题、应用动画、Python 实现与自测习题。

### 资源文件命名

`assets` 下全部路径均为 ASCII 英文命名，便于跨平台拷贝、压缩与上传：

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| 微课视频 | `<小节号>-<英文标题>.mp4` | `assets/micro-lectures/1.1-counting-basics.mp4` |
| 播客音频 | `<小节号>-<英文标题>.mp3` | `assets/podcasts/1.1-counting-basics.mp3` |
| 作者声明 | 固定名 | `assets/podcasts/0-author-statement.mp3` |
| 配套源码 | 沿用书内编号 | `assets/source-code/CH1/1.1.1.py` |

微课与播客同一小节使用完全相同的文件名（仅扩展名不同），便于成对管理。
`assets/source-code/book-code-v2-20250513.zip` 为《书内配套代码》v2 原始归档包，
内容与已解压的 `CH1`…`CH11` 完全一致，仅作版本存档。

## 数字资源如何嵌入

三类资源已按学习动线全量嵌入正文，无需另行打开文件夹：

| 位置 | 内容 |
|------|------|
| 章首 | **本章数字资源**总览页：三类资源数量与总时长，并附小节资源索引表，点击即可跳转 |
| 每个小节的分节页之后 | **微课视频页**：整页 16:9 播放器，先看导学再读正文 |
| 每个小节的小结页之后 | **播客音频页**：波形播放器，可点击波形任意位置跳转 |
| 紧随播客音频页 | **配套源码页**：该节全部 `.py` 文件，点击查看完整高亮源码 |

每章的学习动线为：**看微课 → 读正文 → 跑代码 → 听播客 → 做习题**。

## 操作方式

### 翻页与导航

- **翻页**：`→` / `←` 方向键、空格、`PageUp` / `PageDown`、鼠标滚轮、触屏左右滑动
- **首页 / 末页**：`Home` / `End`
- **目录**：`M`　**幻灯片总览**：`G`　**搜索本章**：`/`
- **收藏本页**：`B`　**字号调节**：`T`　**专注模式**：`F`　**帮助**：`?`
- 右上角「全书目录」按钮可随时返回书目

### 数字资源

- **`V`**：打开数字资源面板（微课视频 / 播客音频 / 配套源码三个分页）
- **`A`**：播放 / 暂停当前小节的播客音频
- **`C`**：打开本章源码浏览器

### 微课视频

视频体积较大，采用**按需加载**：只有点击播放键才会读取文件，翻页浏览不会预载，
因此打开教材始终很快。切换到其他页面时视频自动暂停。

### 播客音频

- 播客由页面底部左侧的**常驻迷你播放器**统一控制，**翻页、查阅源码时不会中断**，
  可以边听边看
- 支持 1× / 1.25× / 1.5× / 2× 倍速切换
- 收听进度按小节自动记忆，下次打开从上次位置继续
- 播放视频时播客会自动暂停，避免声音重叠

### 配套源码

- 253 段源码已**全量内嵌**在教材中，离线可读，无需打开 `assets` 目录
- 源码浏览器左侧按小节分组，右侧为语法高亮的完整代码
- 「复制代码」一键复制单个文件；「下载 .py」保存单个文件；
  「打包下载本章」把本章全部源码合并导出为一个 `.py` 文件
- 原始文件同时保留在 `assets/source-code/CHn/` 下

阅读进度、已读标记、书签与播客收听进度自动保存在浏览器本地（localStorage），
下次打开自动续读。
