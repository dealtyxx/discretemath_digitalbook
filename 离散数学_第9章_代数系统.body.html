9.1.1 定义
7 / 79
定义 9.1.1 ~ 9.1.4

代数运算就是从 S 的幂到 S 的函数

\[\displaystyle f : S^{n}\to S\]

n 为正整数，表示运算是几元的。一元运算 \(f : S \to S\) 把一个元素映到一个元素；二元运算 \(S \times S \to S\) 对任意 a,b 给出 \(c = a \ast b\)；n 元运算把 n 个元素映到一个结果。

是否封闭决定是否成立

取反、倒数、绝对值、平方都是一元运算

对任意实数取反 −a、非零实数取倒数 1/a、取绝对值 |a|、取平方 \(a^{2}\) 都满足一元运算定义。

反例

求逆矩阵（奇异矩阵无逆）、正整数开立方、负数求平方根、对非正数取对数都不封闭，因此不是一元运算。

封闭性是关键

实数加乘、布尔与或都是二元运算

实数集上的加法与乘法 \(R \times R \to R\)、布尔集合上的逻辑与和逻辑或都封闭，是二元运算。

反例

整数集上的除法（1/2 不是整数）、维度不兼容的向量与矩阵乘法都不封闭，因此不是二元运算。

n 元运算

算术平均、最值与求和都是 n 元运算

\[\displaystyle \operatorname{mean}(a_{1},\ldots ,a_{n}) = (a_{1} + \cdots + a_{n}) / n\]

实数集上的算术平均、最大值 max、最小值 min、求和 sum 都把 n 个实数映到一个实数，符合 n 元运算 \(S<sup>n</sup> \to S\) 的定义。

定义 9.1.5

代数系统是集合加上其上的运算

\[\displaystyle \langle A, O_{1}, O_{2}, \ldots , O_{n}\rangle\]

代数系统又称代数结构，由非空集合 A 与定义在 A 上的一个或多个运算组成。可把它想象成一个俱乐部：A 是成员，运算是成员之间互动的规则；一元运算是自己和自己玩，二元是两人互动，m 元是多人一起参与。

定义 9.1.6 / 9.1.7

封闭性、唯一性与算符

若对任意 \(a,b \in S\) 都有 \(a \ast b\) 仍在集合内，则运算具有封闭性；若运算结果不产生另一个不同元素，则具有唯一性。代数系统中 ⊕、∗、☉、∧、∨、∩、∪ 等运算符号称为算符。

用代数系统看小组合作

把学习小组建模为代数系统

集合 A 是小组所有成员；n 元运算是 n 个成员的合作过程；封闭性指讨论与决策都局限在组内、成果归小组共有。

对应

唯一性对应每个成员独特的角色与贡献；算符对应小组的组织与领导结构；运算结果即所有成员互动与贡献共同促成的项目成果。

定义 9.1.8 · 结合律

结合律：运算次序不影响结果

加法、乘法、矩阵乘法、最小公倍数、逻辑与都满足结合律。

\[\displaystyle (a \ast b) \ast c = a \ast (b \ast c)\]
例 9.1.5

设 \(a \odot b = b\)，则 \((a \odot b) \odot c = c\) 且 \(a \odot (b \odot c) = c\)，故 ☉ 可结合。

定义 9.1.9 · 交换律

交换律：交换操作数不改变结果

加法、乘法、向量点积、最大公约数、逻辑或、集合并集都满足交换律。

\[\displaystyle a \ast b = b \ast a\]
例 9.1.6

设 \(a \ast b = a + b - a\cdot b\)，则 \(a \ast b = b + a - b\cdot a = b \ast a\)，故 ∗ 可交换。

吸收律
20 / 79
定义 9.1.11 · 吸收律

吸收律：一个运算吞掉另一个

逻辑运算 \(P \land (P \lor Q) = P\)、集合运算 \(A \cup (A \cap B) = A\) 都满足吸收律。

\[\displaystyle a \oplus (a \ast b) = a\]
例 9.1.8

设 \(a \odot b = \operatorname{max}\{a,b\}\)、\(a \ast b = \operatorname{min}\{a,b\}\)，则 \(a \odot (a \ast b) = a\) 且 \(a \ast (a \odot b) = a\)，二者互为吸收。

幂等律
21 / 79
定义 9.1.12

幂等元：自己运算自己不变

\[\displaystyle a \ast a = a\]

若 \(a \ast a = a\)，则 a 是幂等元；若所有元素都幂等，则运算满足幂等律。逻辑与或、集合交并、最值运算都满足幂等律。例 9.1.9：幂集上的并与交满足 \(A \cup A = A\)、\(A \cap A = A\)，均等幂。

定义 9.1.13

单位元：运算中的中性元素

\[\displaystyle a \ast e = e \ast a = a\]

若存在 e 使对任意 a 都有 \(a \ast e = e \ast a = a\)，则 e 是单位元或幺元。加法的 0、乘法的 1、矩阵乘法的单位矩阵、逻辑与的 True、集合并的空集都是单位元。

单位元的唯一性

左右单位元相等且单位元唯一

\[\displaystyle e_{l} = e_{l} \ast e_{r} = e_{r} = e\]

若 \(e_{l}\)、\(e_{r}\) 分别为左、右单位元，则由 \(e_{l} = e_{l} \ast e_{r} = e_{r}\) 得二者相等；若另有单位元 e′，则 \(e' = e' \ast e = e\)，故单位元唯一。

定义 9.1.14

零元：运算中的吸收元素

\[\displaystyle z \ast a = a \ast z = z\]

定义 9.1.15

逆元：把元素运算回单位元

定义 9.1.16 · 消去律

消去律：相同因子可两边消去

加法、矩阵加法、非零元素的乘法、非零多项式的乘法都满足消去律。

代码 9.2.6 · 验证同态

逐对验证同态等式

对所有 fi, fj，比较先运算后映射与先映射后运算的结果是否一致。

Python 实现
F = ['f0', 'f1', 'f2', 'f3']
def op_F(a, b):
    return F[(F.index(a) + F.index(b)) % 4]
def add4(a, b):
    return (a + b) % 4
def to_z4(f):
    return F.index(f)
def is_homo():
    for a in F:
        for b in F:
            if to_z4(op_F(a, b)) != add4(to_z4(a), to_z4(b)):
                return False
    return True
print(is_homo())   # True

Python 实现
class SharedResourceSystem:
    def __init__(self):
        self.resources = {}
    def add_resource(self, name, qty):
        self.resources[name] = self.resources.get(name, 0) + qty
    def distribute(self, *allocs):
        for name, qty in allocs:
            if self.resources.get(name, 0) >= qty:
                self.resources[name] -= qty
                print(f"{name} 分配 {qty} 单位")
            else:
                print(f"{name} 不足")
s = SharedResourceSystem()
s.add_resource('共享汽车', 10)
s.distribute(('共享汽车', 2))
