定义 4.1.1 · 相容关系

自反加对称即相容

集合 S 上的关系 R 是相容关系，当且仅当满足自反性（任意 a，\(\langle a,a\rangle \in R\)）与对称性（\(\langle a,b\rangle \in R\) 则 \(\langle b,a\rangle \in R\)）。同余、是好友都是相容关系。

例

例 4.1.1：\(R=\{<1,1>,<2,2>,<3,3>,<1,2>,<2,1>,<2,3>,<3,2>\}\) 自反且对称，是相容关系。例 4.1.2：含 <c,a> 却缺 <a,c>，不对称，不是相容关系。

Python 实现
S = {1, 2, 3}
R = {(1,1),(2,2),(3,3),(1,2),(2,1),(2,3),(3,2)}
reflexive = all((x, x) in R for x in S)        # 自反性
symmetric = all((y, x) in R for x, y in R)     # 对称性
print(reflexive, symmetric)   # True True

定理 4.1.1 · 等价类的三条性质

等价类构成集合的划分

(1) 任意等价类非空：\(a\in [a]\)，\([a]\ne \varnothing\)。 (2) 若 a 与 b 不等价，则 \([a]\cap [b]=\varnothing\)。 (3) 所有等价类的并集等于 A。

例 4.1.7 · 三个商集

按奇偶、字母位置、模 3 划分

\((1) A=\{1,\ldots ,6\}\) 按奇偶：{{1,3,5},{2,4,6}}。 \((2) B=\{a,\ldots ,f\}\) 按字母位置差为 3 的倍数：{{a,d},{b,e},{c,f}}。 \((3) C=\{1,\ldots ,9\}\) 按模 3：{{3,6,9},{1,4,7},{2,5,8}}。

Python 实现
A = {1, 2, 3, 4, 5, 6}
def classes_R(A):                      # 按奇偶
    odd  = {x for x in A if x % 2}
    even = {x for x in A if not x % 2}
    return [odd, even]
print(classes_R(A))     # [{1,3,5},{2,4,6}]

C = {1,2,3,4,5,6,7,8,9}
def classes_T(C):                      # 按模3
    cls = {}
    for x in C:
        cls.setdefault(x % 3, set()).add(x)
    return list(cls.values())
print(classes_T(C))

4.1.2 划分与等价关系互转
16 / 105
划分 ⇄ 等价关系

划分与等价关系可相互确定

给定划分，同子集内元素互相等价即得等价关系；给定等价关系，其等价类即得划分。例如划分 {{1,2},{3,4}} 对应等价关系 \(R=(\{1,2\}\times \{1,2\})\cup (\{3,4\}\times \{3,4\})\)。

Python 实现
def partition_to_relation(partition):   # 划分 → 等价关系
    rel = set()
    for subset in partition:
        for a in subset:
            for b in subset:
                rel.add((a, b))
    return rel

print(partition_to_relation([{1, 2}, {3, 4}]))
# {(1,1),(1,2),(2,1),(2,2),(3,3),(3,4),(4,3),(4,4)}

def relation_to_partition(relation):       # 等价关系 → 划分
    partition = []
    for a, b in relation:
        sa = next((s for s in partition if a in s), None)
        sb = next((s for s in partition if b in s), None)
        if sa and sb:
            if sa is not sb:
                sa |= sb; partition.remove(sb)
        elif sa: sa.add(b)
        elif sb: sb.add(a)
        else: partition.append({a, b})
    return partition

S = {('a','a'),('b','b'),('c','c'),('d','d'),('a','b'),
     ('b','a'),('a','c'),('c','a'),('c','b'),('b','c')}
print(relation_to_partition(S))   # [{'a','b','c'}, {'d'}]

例 4.1.11 · 幂集包含关系

\(A=\{a,b,c\}\) 幂集上的包含关系

\(P(A)\) 的 8 个子集按包含关系构成偏序，哈斯图是一个立方体：底层是 ⌀，第二层是单元素集，第三层是双元素集，顶层是 {a,b,c}。

Python 实现
# 例 4.1.10 中 A、B 上的整除关系同样构成偏序，
# 其哈斯图把每个数放在能整除它的数之上，
# 省略可由传递性推出的边。
A = [1,2,3,4,6,8,12,24]
def covers(a, b):          # b 直接盖住 a
    if a == b or b % a: return False
    return not any(a != c != b and c % a == 0 and b % c == 0
                   for c in A)
edges = [(a, b) for a in A for b in A if covers(a, b)]
print(edges)

例 4.1.12 · 找极元与最值

\(P=\{a,b,c,d,e\}\) 链式偏序

偏序 \(\{a\le b,b\le c,c\le d,d\le e,a\le d,b\le e\}\)。没有元素小于 a，a 是唯一极小元也是最小元；没有元素大于 e，e 是唯一极大元也是最大元。

Python 实现
P = {'a','b','c','d','e'}
rel = {('a','b'),('b','c'),('c','d'),
       ('d','e'),('a','d'),('b','e')}
pred = {x: set() for x in P}
succ = {x: set() for x in P}
for x, y in rel:
    succ[x].add(y); pred[y].add(x)
minimal = {x for x in P if not pred[x]}   # 极小元
maximal = {x for x in P if not succ[x]}   # 极大元
print("极小元:", minimal, "极大元:", maximal)
# 极小元: {'a'} 极大元: {'e'}

Python 实现示例 4.1.8 · 最长链与反链

用 networkx 求最长链与最长反链

import networkx as nx
import itertools

P_relations = [('a','b'),('a','c'),('b','d'),('c','e'),('d','f'),('e','f')]
G = nx.DiGraph(); G.add_edges_from(P_relations)

def is_antichain(subset, G):                       # 两两不可比即反链
    return all(not (G.has_edge(u, v) or G.has_edge(v, u))
               for u, v in itertools.combinations(subset, 2))

paths = [p for s in G for t in G for p in nx.all_simple_paths(G, s, t)]
longest = max(len(p) for p in paths)               # 最长链
print("所有最长链:", [p for p in paths if len(p) == longest])

def generate_W(n):                     # W = {2^i − 1}
    return [2**i - 1 for i in range(1, n + 1)]

print("前10个元素:", generate_W(10))
# [1, 3, 7, 15, 31, 63, 127, 255, 511, 1023]
print("小于64:", [x for x in generate_W(10) if x < 64])

def is_function(A, B, R):
    for a in A:
        found = False
        for x, y in R:
            if x == a:
                if found: return False     # 一对多
                found = True
        if not found: return False         # 有元素无对应
    return True

def image_set(A1):
    return {f(x) for x in A1}

    A = set(range(1, 6))               # A={1,2,3,4,5}

坐标变换与逆变换

用旋转 θ 并缩放 s 的变换函数把古代遗址原始坐标转换到现代地图格式，再用逆变换恢复原始坐标，用于历史对比与研究。逆变换需反向执行缩放与旋转。

Python 实现
import numpy as np

def transform(x, y, theta, s):              # 旋转θ并缩放s
    r = np.radians(theta)
    return (s*(x*np.cos(r) - y*np.sin(r)),
            s*(x*np.sin(r) + y*np.cos(r)))

def inverse_transform(x, y, theta, s):      # 逆变换
    r = np.radians(-theta)
    return ((x*np.cos(r) - y*np.sin(r)) / s,
            (x*np.sin(r) + y*np.cos(r)) / s)

t = transform(1, 2, 45, 2)
print("变换后:", t)
print("恢复后:", inverse_transform(*t, 45, 2))   # (1.0, 2.0)
