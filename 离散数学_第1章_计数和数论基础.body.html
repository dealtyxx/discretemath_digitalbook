定义 1.1.3 · 排列

选取并考虑顺序

从 n 个不同元素中选取 r 个并排序（\(r \le n\)），记为 \(P(n, r)\)。本质是乘法法则的应用，强调顺序：a,b 与 b,a 是不同排列；当 \(r = n\) 时为全排列。

\[\displaystyle P(n, r) =\frac{n!}{(n - r)!}\]

定义 1.1.4 · 多重集排列

含重复元素的排列

集合有 n 个元素，第 i 类重复 \(k_{i}\) 次（\(n = k_{1} + \ldots + k_{r}\)），排列数需消去重复带来的等价。

\[\displaystyle \frac{n!}{k_{1}! \times k_{2}! \times \ldots \times k_{r}!}\]
例 \(1.1.4 \cdot S = \{2\times A, 3\times B\}\)

\(5!/(2!\times 3!) = 10\) 种排列。

Python 实现
from itertools import permutations

def find_permutations(multiset):
    s = ''.join(c * k for c, k in multiset.items())
    perms = set(permutations(s))      # set去重
    return [''.join(p) for p in perms]

multiset = {'A': 2, 'B': 3}           # S={2×A,3×B}
result = find_permutations(multiset)
print(f"Number: {len(result)}")
print("Permutations:", result)

定义 1.1.6 · 多重集组合

可重复元素中按次数限制选取

在元素可重复的集合中，按出现次数限制选出指定数量，不计顺序。

例 1.1.6 · {3×A, 2×B, 1×C} 选 3 个

共 6 种：AAA, AAB, AAC, ABC, ABB, BBC。

Python 实现
from itertools import combinations

def find_combinations(multiset, r):
    elems = [c for c, k in multiset.items()
                 for _ in range(k)]
    combs = set(combinations(elems, r))   # 去重
    return [''.join(c) for c in combs]

multiset = {'A': 3, 'B': 2, 'C': 1}
result = find_combinations(multiset, 3)
print(f"Number: {len(result)}")
print("Combinations:", result)

定理 1.1.1 · 鸽巢原理（抽屉原理）

1834 年由狄利克雷提出

设 n 和 m 为正整数，若 n 个物体放入 m 个容器且 n > m，则至少有一个容器包含不止一个物体。

证明（反证法）：设每个容器至多放一个物体，则最多放 m 个；但共有 n > m 个物体，必有物体无处可放，假设矛盾，定理成立。

Python 实现示例 1.1.5 · 鸽巢计数

尽可能平均分配时，至少多少城市获得多于一种小吃

def min_cities_with_extra(num_snacks, num_cities):
    """在『尽可能平均分配』的前提下，至少有多少城市分到多于一种。"""
    if num_snacks <= num_cities:               # 小吃不多于城市，则无城市超过一种
        return 0
    extra_snacks = num_snacks - num_cities     # 平均分配后剩余、须再分摊的数量
    return min(extra_snacks, num_cities)

num_snacks = 20                                # 小吃总数
num_cities = 14                                # 城市总数
print(min_cities_with_extra(num_snacks, num_cities))   # 输出: 6

# 注：若不要求平均分配，鸽巢原理只保证至少 1 个城市分到多于一种。

七条基本性质

整除关系的代数性质

  1. a | a，自反
  2. 若 a|b 且 b|a，则 \(a = \pm b\)
  3. 若 a|b 且 b|c，则 a|c（传递）
  4. 若 a|b，则对任意整数 k，a|kb
  5. 若 a|b 且 a|c，则 \(a|(b+c)\) 与 a|(b−c)
  6. 若 a|b，则对任意整数 c，a|bc
  7. 若 a|b 且 \(b\ne 0\)，则 \(|a| \le |b|\)

三条性质的证明思路

定义 1.2.2 · 模运算（同余）

同余刻画余数相同

给定正整数 n，若存在整数 k 使 \(a - b = kn\)，则 a 与 b 在模 n 下同余，记 \(a \equiv b (\operatorname{mod} n)\)。性质：自反、对称、传递，且对加法与乘法封闭。

例 1.2.2

\((1) 2+3 = 5 \equiv 0 (\operatorname{mod} 5)\)。 (2) 3 点过 12 小时仍是 3 点：\(3+12 \equiv 3 (\operatorname{mod} 12)\)。 \((3) 3\times 4 = 12 \equiv 5 (\operatorname{mod} 7)\)。

Python 实现
n = 5            # 加法性质
a, c = 2, 3
print((a + c) % n == 0)

n = 7            # 乘法性质
a, c = 3, 4
print((a * c) % n)   # 5

定义 1.2.3 · 素数与合数

素数是数的原子

正整数 p 的因数只有 1 和 p 自身则为素数；正整数 n 有 1 和 n 之外的正因数则为合数。

2 是最小的素数且是唯一的偶素数，3 是素数；\(4 = 2\times 2\)、\(15 = 3\times 5\) 是合数。大于 1 的整数要么是素数，要么是合数。

定理 1.2.1 · 唯一分解定理

每个整数唯一分解为素数乘积

每个大于 1 的整数 n 都可唯一地分解为素数的乘积：

\[\displaystyle n = p_{1}^{k_{1}}\times p_{2}^{k_{2}}\times \ldots \times p_{r}^{k_{r}}\]

其中 \(p_{1}, \ldots , p_{r}\) 为互异素数，\(k_{1}, \ldots , k_{r}\) 为正整数。例如 \(20 = 2^{2}\times 5\)，\(100 = 2^{2}\times 5^{2}\)。

逐步除尽，得到素因数及其指数

def prime_factors(n):
    factors = []
    exponent = []
    while n % 2 == 0:                          # 先取出所有因数2
        factors.append(2)
        n //= 2
    for i in range(3, int(n**0.5) + 1, 2):     # 从3开始找更大的素因数
        while n % i == 0:
            factors.append(i)
            n //= i
    if n > 1:                                  # 剩下的n本身是素因数
        factors.append(n)
    unique_factors = sorted(set(factors))      # 排序去重，顺序确定
    exponent = [factors.count(f) for f in unique_factors]
    return unique_factors, exponent

n = 100
factors, exponents = prime_factors(n)
print(f"{n} 的素因数分解为:")
for factor, exponent in zip(factors, exponents):
    print(f"{factor}^{exponent}", end=" * ")

高效筛出范围内所有素数

def sieve_of_eratosthenes(N):
    is_prime = [True] * (N + 1)
    is_prime[0] = is_prime[1] = False
    for p in range(2, int(N**0.5) + 1):
        if is_prime[p]:
            for i in range(p*p, N+1, p):   # 标记倍数
                is_prime[i] = False
    return [p for p in range(2, N+1)
                if is_prime[p]]

        return 0
    return abs(a * b) // gcd(a, b)

定义 1.2.7 · 同余方程

高斯在算术研究中系统介绍

同余方程 \(ax \equiv b (\operatorname{mod} n)\)，即存在整数 k 使 \(ax - b = kn\)。若 \(\operatorname{gcd}(a, n) = 1\)，则对任意 b 在模 n 意义下有唯一解（解恰为一个剩余类）；否则可能有多解或无解。

Python 实现
def linear_congruence(a, b, m):
    return [x for x in range(m)
                if (a * x) % m == b]

a, b, m = 3, 4, 7        # 3x ≡ 4 (mod 7)
print(linear_congruence(a, b, m))   # [6]

两两互质模数下的联立同余

例 1.2.9 · 算法 1.2.7

求解 \(x \equiv 2 (\operatorname{mod} 3)\)，\(x \equiv 3 (\operatorname{mod} 5)\)

  1. \(N = 3 \times 5 = 15\)
  2. \(n_{1}=3\)：\(N_{1}=5\)，5 的模 3 逆元为 2（\(5\times 2 \equiv 1\)）
  3. \(n_{2}=5\)：\(N_{2}=3\)，3 的模 5 逆元为 2（\(3\times 2 \equiv 1\)）
  4. \(x = 2\times 5\times 2 + 3\times 3\times 2 = 38\)，\(38 \operatorname{mod} 15 = 8\)
Python 实现
def crt(equations):
    N = 1
    for ai, ni in equations:
        N *= ni
    x = 0
    for ai, ni in equations:
        Ni = N // ni
        Mi = pow(Ni, -1, ni)   # Ni模ni的逆元
        x += ai * Ni * Mi
    return x % N               # 最小非负解

print(crt([(2, 3), (3, 5)]))   # 8

定理 1.2.3 · 欧拉定理

互质时幂次回到 1

def euler_phi(n):
    result, p = n, 2
    while p * p <= n:
        if n % p == 0:
            while n % p == 0:
                n //= p
            result -= result // p
        p += 1
    if n > 1:
        result -= result // n
    return result

a, n = 2, 9
print(pow(a, euler_phi(n), n))   # 1

    n = len(s)
    hash_value = 0
    for i in range(n):
        hash_value += ord(s[i]) * a ** (n - i - 1)
    return hash_value % p

案例四 · RSA

1977 年由 Rivest、Shamir、Adleman 提出

安全性基于大数素因数分解的困难性，是现代公钥加密的基石。密钥生成：选大素数 p、q，\(n = pq\)，\(φ(n) = (p-1)(q-1)\)，选与 φ(n) 互质的 e，求 d 使 \(de \equiv 1 (\operatorname{mod} φ(n))\)。

\[\displaystyle \text{加密} C = M^{e} \operatorname{mod} n \text{解密} M = C^{d} \operatorname{mod} n\]

公钥对 (n, e)，私钥对 (n, d)。不知 p、q 时对密文解密极其困难。

Python 实现示例 1.3.4 · RSA 加解密

生成密钥、加密与解密

import random
from math import gcd
from sympy import isprime, mod_inverse

# 教学示例：未做消息填充(padding)，请勿用于生产环境
def generate_large_prime(keysize):
    while True:
        num = random.getrandbits(keysize)
        num |= (1 << keysize - 1) | 1     # 保证位长足够且为奇数
        if isprime(num):
            return num

def generate_keys(keysize):
    p = generate_large_prime(keysize)
    q = generate_large_prime(keysize)
    while q == p:                        # 排除 p=q，否则 φ(n) 公式失效
        q = generate_large_prime(keysize)
    n = p * q
    phi_n = (p - 1) * (q - 1)            # φ(n)=(p-1)(q-1)
    e = 65537                            # 常用公钥指数
    if gcd(e, phi_n) != 1:               # 确保 e 与 φ(n) 互质
        return generate_keys(keysize)    # 不互质则重新生成
    d = mod_inverse(e, phi_n)            # 私钥d
    return ((n, e), (n, d))

def encrypt(public_key, plaintext):
    n, e = public_key
    return pow(plaintext, e, n)

def decrypt(private_key, ciphertext):
    n, d = private_key
    return pow(ciphertext, d, n)

public_key, private_key = generate_keys(1024)
ciphertext = encrypt(public_key, 12345)
print("密文:", ciphertext)
print("解密后的明文:", decrypt(private_key, ciphertext))

案例五 · 资源分配

用最大公因数确定分配基本单位

某机构有总量为 R 的一种资源、M 个班级，按学生人数成比例分配。用各班学生数的 gcd 作为基本单位保证公平，再用排列组合分析方案优化利用率。

例

总资源 100，各班学生 [30, 20, 50]，按比例分配。

Python 实现
from math import gcd
from functools import reduce

def find_gcd(nums):
    return reduce(gcd, nums)

def allocate_resources(resources, spc):
    g = find_gcd(spc)            # 学生数gcd作基本单位
    total_units = sum(spc) // g
    per_unit = resources // total_units
    return [s // g * per_unit for s in spc]

resources = 100
students_per_class = [30, 20, 50]
print(allocate_resources(resources,
                         students_per_class))
