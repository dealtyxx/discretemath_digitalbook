7.1.1 图的基本概念
7 / 71
定义 7.1.1 至 7.1.3

图由顶点集与边集构成

\[\displaystyle G = \langle V, E, φ\rangle\]

V 是顶点集，E 是边集，φ 把边映射到顶点的有序对或无序对。边对应无序对 \((v_{i},v_{j})\) 是无向边，全无向边的图是无向图；对应有序对 \(\langle v_{i},v_{j}\rangle\) 是有向边，全有向边的图是有向图。

混合图、加权图、零图与特殊边

混合图同时含有向边与无向边。加权图 \(G=\langle V,E,w\rangle \text{每条边赋权重}\)，如管道流量、车流密度、城市距离。零图无边 \(E=\varnothing\)，平凡图是只有一个顶点的零图。

7.1.1 相邻邻接关联与邻域
11 / 71
定义 7.1.11 至 7.1.14

相邻、关联、连通与邻域

顶点与顶点直接相连为相邻（邻接）；边与它所连接的顶点为关联（顶点-边关系）；两顶点间存在通路为连通（可达）。顶点 v 的邻域 N(v) 是与 v 相邻的所有顶点，闭邻域 \(N[v]=N(v)\cup \{v\}\)。

例

例 7.1.7：\(E=\{(1,2),(2,3),(3,4)\}\)，顶点 2 的邻域是 {1,3}，闭邻域是 {1,2,3}。

Python 实现
import networkx as nx
G = nx.Graph()
G.add_edges_from([(1, 2), (2, 3), (3, 4)])
print("顶点2的邻域:", list(G.neighbors(2)))          # [1, 3]
print("顶点2的闭邻域:", list(G.neighbors(2)) + [2])   # [1, 3, 2]

度、入度与出度

无向图中顶点 v 的度 \(\operatorname{deg}(v)\) 是与它相连的边数。最大度 Δ(G)、最小度 δ(G)。

有向图中入度 \(\operatorname{deg}^{-}(v)\) 是指向 v 的边数，出度 \(\operatorname{deg}^{+}(v)\) 是从 v 出发的边数。例 7.1.8：顶点 3 连接 1,2,4 度为 3。

7.1.2 握手定理
13 / 71
定理 7.1.1 · 握手定理

所有顶点度数之和等于边数的两倍

\[\displaystyle \sum \operatorname{deg}(v) = 2|E| \sum \operatorname{deg}^{+}(v) = \sum \operatorname{deg}^{-}(v) = |E|\]

每条无向边对总度数贡献 2，故度数和为 2|E|。例 7.1.9：无向图 \(\operatorname{deg}(A)=2, \operatorname{deg}(B)=3, \operatorname{deg}(C)=2, \operatorname{deg}(D)=3\)，度数和 \(10 = 2\times 5\)，边数 \(|E|=5\)，验证成立。

7.1.2 度的性质与可图化
14 / 71
定理 7.1.2 与 7.1.3

奇数度顶点个数必为偶数

任何图中度数为奇数的顶点个数必为偶数。度数序列之和必为偶数（必要条件），但和为偶数不足以保证可图化，如 (3,3,3,2) 和为偶数却不可图化。

Python 实现
# 握手定理：边数 = 度数之和 // 2（度数和须为偶）
print(sum([2, 3, 2, 3]) // 2)               # 例7.1.9: 5 条边
# 度数为奇数的顶点个数必为偶数
print(len([d for d in [2, 4, 5, 1, 3] if d % 2]))   # 3 个奇度顶点

def degree_sum_even(seq):       # 可图化的必要条件
    return sum(seq) % 2 == 0
print(degree_sum_even([3, 3, 2, 2, 2]))     # True（和为偶）

7.1.3 图同构
15 / 71
定义 7.1.17 · 图同构

存在保持边连接的双射即同构

若存在双射 \(f:V_{1}\to V_{2}\)，使 (u,v) 是 \(G_{1}\) 的边当且仅当 (f(u),f(v)) 是 \(G_{2}\) 的边，则 \(G_{1}\) 与 \(G_{2}\) 同构。

必要条件：顶点数相等、边数相等、度数序列相同、有相同的子结构（如圈、路径）。这些条件不总是充分，复杂图的同构通常需用算法求解。例 7.1.13：\(a\to 1,b\to 2,c\to 3\) 使 \(K_{3}\) 同构。

7.1.4 几种典型图
18 / 71
定义 7.1.18、7.1.19 与 定理 7.1.4

n 阶图与 K-正则图

n 阶图有 n 个顶点。K-正则图每个顶点都恰好与 K 个其他顶点相连。定理 7.1.4：K-正则图有 n 个顶点时边数为 nK/2。例 7.1.15：4-正则 10 顶点有 20 条边；3-正则 8 顶点有 12 条边。

Python 实现
def edges_k_regular(n, K):       # K-正则图边数 = nK/2
    return n * K // 2
print(edges_k_regular(10, 4))   # 20
print(edges_k_regular(8, 3))    # 12

7.1.4 完全图与彼得森图
19 / 71
定义 7.1.20 至 7.1.22 与 定理 7.1.5

完全图、竞赛图、彼得森图与立方体图

完全图 \(K_{n}\) 每对顶点恰有一条边。定理 7.1.5：\(K_{n}\) 是 (n−1)-正则图，有 n(n−1)/2 条边。有向完全图每对顶点有两条相反有向边；竞赛图每对顶点只有一条有向边。彼得森图有 10 顶点 15 边、每点度 3；K-立方体图 \(Q_{n}\) 顶点为 n 位二进制串、仅一位不同则相连。

Python 实现
def edges_complete(n):  return n * (n - 1) // 2
def degree_complete(n): return n - 1
print(edges_complete(7))    # K7: 21 条边
print(degree_complete(6))   # K6: 每个顶点度为 5

7.1.5 图的运算
20 / 71
定义 7.1.23 至 7.1.27

子图、生成子图、导出子图、补图与图操作

子图 H 满足 \(V_{H}\subseteq V_{G}\) 且 \(E_{H}\subseteq E_{G}\)；真子图不同于母图。生成子图保留全部顶点而取部分边（\(V_{H}=V_{G}\)）；导出子图取部分顶点及其在母图中两端点都在该顶点子集内的所有边（记 \(G[V_{H}]\)）。补图与原图同顶点集，边集是原图中不存在的所有可能边。

图操作：删除顶点会同时删除关联的边；删除边只移除该边；收缩边把两端点合并为新顶点；加新边在两个非邻接顶点间加边。

不交、交、并、差运算

连通、连通分量与极大连通子图

print("连通:", nx.is_connected(G))                  # False

# [{1,2,3}, {4,5,6}, {7,8}, {9}]

算法 7.2.2 · Dijkstra

Dijkstra 求单源最短路径

每次选最小未处理顶点，更新其相邻顶点的最短估计值。适用于非负权图。例 7.2.16：从 A 出发，到 \(B=1\)、\(C=3\)、\(D=4\)。

Python 实现
import heapq
def dijkstra(graph, start):
    dist = {v: float('inf') for v in graph}
    dist[start] = 0
    pq = [(0, start)]
    while pq:
        d, u = heapq.heappop(pq)
        if d > dist[u]: continue
        for v, w in graph[u].items():
            if d + w < dist[v]:
                dist[v] = d + w
                heapq.heappush(pq, (dist[v], v))
    return dist

g = {'A':{'B':1,'C':3}, 'B':{'A':1,'C':2,'D':4},
     'C':{'A':3,'B':2,'D':1}, 'D':{'B':4,'C':1}}
print(dijkstra(g, 'A'))   # {'A':0,'B':1,'C':3,'D':4}

算法 7.2.3 · Floyd-Warshall

Floyd-Warshall 求所有顶点对最短路径

初始化距离矩阵，对每个中转顶点 k 更新 \(D[i][j]=\operatorname{min}(D[i][j], D[i][k]+D[k][j])\)。可处理负权边但不能处理负权环。例 7.2.18 计算得到全对最短路径矩阵。

Python 实现
def floyd_warshall(w):
    n = len(w)
    d = [[float('inf') if i != j and w[i][j] == 0 else w[i][j]
          for j in range(n)] for i in range(n)]
    for k in range(n):
        for i in range(n):
            for j in range(n):
                d[i][j] = min(d[i][j], d[i][k] + d[k][j])
    return d

weights = [[0,2,4,0],[0,0,1,0],[0,0,0,2],[0,-3,0,0]]
for row in floyd_warshall(weights):
    print(row)
