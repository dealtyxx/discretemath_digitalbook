定义 8.1.1

走遍每条边恰好一次

欧拉回路是通过图中每条边恰好一次并返回起点的路径；欧拉通路通过每条边恰好一次但不要求回到起点。

Fleury 算法

Fleury：优先走非割边

  1. 任选一个节点作为起点（若有奇度节点则从奇度节点起）
  2. 选一条边移动到相邻节点，优先选择非割边以保持连通
  3. 走过一条边后立即把它从图中删除
  4. 重复直到所有边被删除，得到的闭合路径即欧拉回路
Python 实现
import networkx as nx
def is_bridge(g, u, v):
    c0 = nx.number_connected_components(g)
    g.remove_edge(u, v)
    c1 = nx.number_connected_components(g)
    g.add_edge(u, v)
    return c1 > c0
def fleury(g):
    u = next(iter(g.nodes))
    for v in g.nodes:
        if g.degree[v] % 2 != 0:
            u = v; break
    path = [u]
    while g.number_of_edges() > 0:
        for v in list(g.neighbors(u)):
            if not is_bridge(g, u, v) or g.degree[u] == 1:
                path.append(v)
                g.remove_edge(u, v)
                u = v; break
    return path

Hierholzer 算法

Hierholzer：拼接回路片段

从起点遍历构造一个闭合回路片段；若仍有未用边，则在含未用边的节点上构造新片段并合并。其效率高于 Fleury，是大型图求欧拉回路的首选。

Python 实现
import networkx as nx
def hierholzer(g):
    u = next(iter(g.nodes))
    for v in g.nodes:
        if g.out_degree(v) > 0:
            u = v; break
    stack = [u]; path = []
    while stack:
        u = stack[-1]
        if g.out_degree(u) == 0:
            path.append(u); stack.pop()
        else:
            v = next(g.neighbors(u))
            stack.append(v)
            g.remove_edge(u, v)
    return path[::-1]

def is_safe(v, graph, path, pos):
    if graph[path[pos - 1]][v] == 0:   # 与前一节点不相邻
        return False
    if v in path:                      # 节点已在路径中
        return False
    return True

def ham_util(graph, path, pos):
    if pos == len(graph):              # 所有节点已加入
        return graph[path[pos - 1]][path[0]] == 1
    for v in range(1, len(graph)):
        if is_safe(v, graph, path, pos):
            path[pos] = v
            if ham_util(graph, path, pos + 1):
                return True
            path[pos] = -1             # 回溯
    return False

def is_hamiltonian(graph):
    path = [-1] * len(graph)
    path[0] = 0
    return ham_util(graph, path, 1)

匈牙利算法思想

不断寻找可增广路径以扩大匹配

def has_k5(graph):                       # 是否含 K5 子图
    nodes = list(graph.keys())
    from itertools import combinations
    for c in combinations(nodes, 5):
        if all(b in graph[a] for a in c for b in c if a != b):
            return True
    return False

def has_k33(graph):                      # 是否含 K3,3 子图
    nodes = list(graph.keys())
    from itertools import combinations
    for six in combinations(nodes, 6):
        p1, p2 = six[:3], six[3:]
        if all((b in graph[a]) or (a in graph[b])
               for a in p1 for b in p2):
            return True
    return False

def is_planar(graph):
    return not (has_k5(graph) or has_k33(graph))

BFS 广度优先

BFS：逐层访问，易找最短路径

从起点出发逐层访问邻居并标记已访问，适用于最短路径搜索，可能占用较多内存。注意 BFS 本身不直接构造最小生成树。

Python 实现
from collections import deque
def bfs(graph, start, end):
    visited = {start}
    queue = deque([(start, [start])])
    while queue:
        current, path = queue.popleft()
        if current == end:
            return path
        for nb in graph[current]:
            if nb not in visited:
                visited.add(nb)
                queue.append((nb, path + [nb]))
    return None

def dfs(graph, current, end, path=None, visited=None):
    if path is None: path = []
    if visited is None: visited = set()
    path.append(current)
    if current == end:
        return path
    visited.add(current)
    for nb in graph[current]:
        if nb not in visited:
            res = dfs(graph, nb, end, path, visited)
            if res: return res
    path.pop()
    return None

自底向上构造

对一组权重构造哈夫曼树

对权重 2,2,2,3,4,6,6,7,9,12,13，每次合并两个最小权重的节点，逐步得到最优树。

Python 实现
import heapq
class Node:
    def __init__(self, value, weight):
        self.value, self.weight = value, weight
        self.left = self.right = None
    def __lt__(self, other):
        return self.weight < other.weight

def build_huffman(elements):
    pq = [Node(v, w) for v, w in elements]
    heapq.heapify(pq)
    while len(pq) > 1:
        a = heapq.heappop(pq)
        b = heapq.heappop(pq)
        m = Node(None, a.weight + b.weight)
        m.left, m.right = a, b
        heapq.heappush(pq, m)
    return pq[0]

根树 · DFS / BFS

智能农业监测系统

把监测系统建模为根树：根为整个农场、子节点为区域、叶子为传感器。用 DFS 深入分析特定区域，用 BFS 快速获取所有区域状态概览。

Python 实现
class TreeNode:
    def __init__(self, name, data=None):
        self.name, self.data = name, data
        self.children = []
    def add_child(self, c):
        self.children.append(c)

def dfs(node, depth=0):
    print(" " * depth + f"{node.name}: {node.data}")
    for c in node.children:
        dfs(c, depth + 1)

def bfs(root):
    from collections import deque
    queue = deque([(root, 0)])
    while queue:
        node, depth = queue.popleft()
        print(" " * depth + f"{node.name}: {node.data}")
        for c in node.children:
            queue.append((c, depth + 1))
