定义 5.1.13 与 5.1.14

全功能联结词组与极小联结词组

全功能联结词组 {¬,∧,∨,→,↔} 能构建任何逻辑等价命题。极小联结词组用最少联结词表达全部命题，如 {¬,∧}：\(P\lor Q \Leftrightarrow \neg (\neg P\land \neg Q)\)，\(P\to Q \Leftrightarrow \neg (P\land \neg Q)\)。

Python 实现
def OR(p, q):  return not (not p and not q)        # ∨
def IMP(p, q): return not (p and not q)            # →
def IFF(p, q): return (not (p and not q)) and \
                      (not (q and not p))          # ↔

p, q = True, False
print("p ∨ q =", OR(p, q))    # True
print("p → q =", IMP(p, q))   # False
print("p ↔ q =", IFF(p, q))   # False

命题公式的递归构造

命题公式由命题变元、联结词和括号组成：单个变元是公式；若 A 是公式则 \(\neg A\) 是公式；若 A、B 是公式则 \((A\land B)\)、\((A\lor B)\)、\((A\to B)\)、\((A\leftrightarrow B)\) 都是公式；有限次应用上述规则得到的字符串是命题公式。

巴科斯范式 BNF 用形式化文法描述命题公式的结构规则。例 5.2.1：\(\neg (P\lor Q)\) 可由 BNF 规则逐层展开构建。例 5.2.2：\((\land B)\) 等不是合法命题公式。

5.2.1 公式层次
26 / 91
定义 5.2.4 · 公式层次

联结词嵌套的深度

单个变元为 0 层公式；\(\neg B\) 比 B 高一层；\(A\land B\)、\(A\lor B\)、\(A\to B\)、\(A\leftrightarrow B\) 的层次为两子公式层次的较大值加 1。例 5.2.5：\((\neg P\land Q)\to R\) 是 3 层，\((\neg (P\to \neg Q))\land ((R\lor S)\leftrightarrow \neg P)\) 是 4 层。

Python 实现
import re

def depth(f):
    f = f.replace(' ', '')
    ops = ['↔', '→', '∨', '∧', '¬']        # 优先级低到高
    def valid(s):
        c = 0
        for ch in s:
            c += (ch == '(') - (ch == ')')
            if c < 0: return False
        return c == 0
    def split(s, op):
        if op == '¬':
            return [s[1:]] if s and s[0] == '¬' else None
        d, parts, cur = 0, [], []
        for ch in s:
            if ch == '(': d += 1
            elif ch == ')': d -= 1
            elif ch == op and d == 0:
                parts.append(''.join(cur)); cur = []; continue
            cur.append(ch)
        if cur: parts.append(''.join(cur))
        return parts if len(parts) > 1 else None
    def parse(s):
        if not s: return 0
        while s and s[0] == '(' and s[-1] == ')' and valid(s[1:-1]):
            s = s[1:-1]
        if re.match(r'^[A-Z]$', s): return 0
        return max((1 + max(parse(p) for p in split(s, op))
                    for op in ops if split(s, op)), default=0)
    return parse(f)

print(depth("(¬P∧Q)→R"))                 # 3
print(depth("(¬(P→¬Q))∧((R∨S)↔¬P)"))     # 4

定义 5.3.4 至 5.3.6

可靠性、一致性与完备性

可靠性：从真前提出发推出的结论也为真，即不证明任何假命题。一致性：系统内不会同时证明某命题及其否定为真，即没有矛盾。完备性：所有在一切解释下为真的命题都能在系统内被证明。

理想的推理系统应同时具备三者：证明所有真命题（完备）、不证明任何假命题（可靠）、内部无矛盾（一致），设计时需平衡三者。

案例一 · 两弹一星

用推理验证项目能否完成

符号化：培养与经费 \(P\land F\to \text{原子弹} A\)；A 与设备经费 \(A\land E\land F\to \text{氢弹} H\)；H 与经费 \(H\land F\to \text{卫星} S\)；已知 P、E、F。经演算推证逐步得 A、H、S，结论 \(A\land H\land S\) 成立，可成功完成两弹一星。

Python 实现
from sympy import symbols
from sympy.logic.boolalg import And, Implies, Not
from sympy.logic.inference import satisfiable
P, F, A, E, H, S = symbols('P F A E H S')
premises = And(Implies(And(P, F), A),       # 培养∧经费→原子弹
               Implies(And(A, E, F), H),    # 原子弹∧设备∧经费→氢弹
               Implies(And(H, F), S),       # 氢弹∧经费→卫星
               P, E, F)
conclusion = And(A, H, S)
# 结论有效 ⟺ 前提∧¬结论 不可满足
print("可完成" if not satisfiable(And(premises, Not(conclusion)))
      else "无法完成")

案例二 · 深度学习

用推理验证项目可行性

数据预处理与网络结构 \(A\land B\to \text{训练} H\)；H 与团队协同 \(H\land E\to \text{验证} F\)；验证 \(F\to \text{完成} G\)。已知 A、B、C、D、E。经演算推证逐步得 H、F，最终结论 G 成立，可成功完成深度学习项目。

Python 实现
from sympy import symbols
from sympy.logic.boolalg import And, Implies, Not
from sympy.logic.inference import satisfiable
A, B, C, D, E, F, G, H = symbols('A B C D E F G H')
conditions = And(Implies(And(A, B), H),   # 数据∧结构→训练
                 Implies(And(D, C), H),   # 资源∧算法→训练
                 Implies(And(H, E), F),   # 训练∧协同→验证
                 Implies(F, G),           # 验证→完成
                 A, B, D, C, E)
# G 是有效结论 ⟺ 前提∧¬G 不可满足
valid = not satisfiable(And(conditions, Not(G)))
print("可以成功完成深度学习项目:", valid)
