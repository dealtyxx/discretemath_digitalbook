5 / 69
定义 11.1.1

环：加法成交换群，乘法成半群，二者由分配律连接

\[\displaystyle a \cdot (b + c) = a \cdot b + a \cdot c\]

环 R 带加法与乘法两种运算：加法满足封闭、结合、有单位元 0、有逆元 −a、交换；乘法满足封闭、结合；加法与乘法之间满足左右分配律。

群与环的区别
6 / 69
定义 11.1.2 · 可换环

环比群多一种运算

群通常只有一种二元运算，环有加法与乘法两种二元运算

环中加法构成交换群，乘法只需封闭、结合并满足分配律

环中加法每个元素都有逆元，乘法不要求每个元素可逆

若环的乘法还满足交换律，则称为可换环

定义 11.1.3

整数模 n 的同余类环 \(Z_{n}\)

定义 11.1.10

理想：对环元素乘法有吸收性的子群

加法子群加吸收性

2Z 是整数环 Z 的理想

定义 11.2.1

格：任意两元都有上确界与下确界

非空集合 L 带偏序关系 ≤，若任意 a,b 都有唯一最小上界 \(a\lor b\)（上确界）与唯一最大下界 \(a\land b\)（下确界），则 L 是格。

\[\displaystyle a \lor b \text{上确界} \text{，} a \land b \text{下确界}\]

并交即上下确界

幂集与整除关系都构成格

幂集在包含关系下成格：上确界是并集、下确界是交集。整数在整除关系下成格：上确界是最小公倍数、下确界是最大公约数。

布尔代数定律
50 / 69
11 条基本定律

布尔代数的十一条基本定律

  1. 交换律：\(a \lor b = b \lor a\)，\(a \land b = b \land a\)
  2. 结合律：\((a \lor b) \lor c = a \lor (b \lor c)\)
  3. 分配律：\(a \lor (b \land c) = (a \lor b) \land (a \lor c)\)
  4. 幂等律：\(a \lor a = a\)，\(a \land a = a\)
  5. 单位元律：\(a \lor 0 = a\)，\(a \land 1 = a\)
  6. 零元律：\(a \lor 1 = 1\)，\(a \land 0 = 0\)
  7. 互补律：\(a \lor \neg a = 1\)，\(a \land \neg a = 0\)
  8. 双重否定：\(\neg (\neg a) = a\)
  9. 吸收律：\(a \lor (a \land b) = a\)
  10. 德摩根律：\(\neg (a \lor b) = \neg a \land \neg b\)
  11. 德摩根律：\(\neg (a \land b) = \neg a \lor \neg b\)
  12. 对偶原理：∨ 与 ∧、0 与 1 互换后定理仍成立

有限环 · 线性码

基于环的纠错线性码

在模 p 的整数环 Z/pZ 上构造生成矩阵 G，由信息向量与 G 的乘积得到码字，再用所有非零码字的最小汉明重量确定最小距离 d，d 越大纠错能力越强。

Python 实现
import numpy as np
class LinearCode:
    def __init__(self, p, G):
        self.p = p
        self.G = np.array(G)
    def encode(self, u):
        return np.dot(np.array(u) % self.p, self.G) % self.p
    def hamming_weight(self, v):
        return np.sum(v != 0)
    def min_distance(self):
        from itertools import product
        m, n = self.G.shape
        dmin = n
        for u in product(range(self.p), repeat=m):
            if not any(u):
                continue
            w = self.hamming_weight(self.encode(u))
            if 0 < w < dmin:
                dmin = w
        return dmin

环同态 · 同态加密

环同态加密系统

设计满足加法同态的加密映射 \(E : Z_{n} \to Z_{m}\)，取与 m 互素的密钥 k，令 \(E(a) = a\cdot k \operatorname{mod} m\)，解密用乘法逆元 \(D(c) = c\cdot k^{-1} \operatorname{mod} m\)。密文可直接相加而保持明文加法结构。

Python 实现
from sympy import mod_inverse
class HomomorphicEncryption:
    def __init__(self, n, m, k):
        self.n, self.m, self.k = n, m, k
        self.k_inv = mod_inverse(k, m)
    def encrypt(self, msg):
        return (msg * self.k) % self.m
    def decrypt(self, c):
        return (c * self.k_inv) % self.m
    def add(self, c1, c2):
        return (c1 + c2) % self.m
